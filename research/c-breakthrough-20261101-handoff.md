## Correctness, integrity and evidence rules
- Every compiled candidate is a COMPLETE solver, not an isolated parser benchmark. All verified CI runs include published full seed1 SHA and exact independent full seeds 11/29, adversarial quote/BOM/name collision cases, ASan/UBSan, TSan, offline pinned Docker/sandbox.
- Do not replace byte-exact equality with long-name fingerprints. Empty quoted and unquoted names are identical. Trailing spaces distinguish names, quoted escape pairs contribute 1 decoded byte, BOMs skip only at record boundaries, signed amounts and extrema use cents.
- Source-paired workflow lives at `.github/workflows/research-c-paired.yml` on incumbent-unmap, tiles-unmap, tile-prefetch branches; this locally regenerates seed1, builds frozen f46c57e and each source using identical pinned GCC15 PGO Dockerfiles, executes twelve alternating seed1 full-run hash checks and twelve fresh-container cgroup checks. It has a full-history checkout and writable /out. All three corrected workflows PASSED: #41291043657, #41291046511 and #41291049157. Earlier runs failed only because checkout was shallow, then /out lacked unprivileged permissions, and those workflow harness errors were fixed; no source correctness failure was involved.
- GitHub Actions medians and memory are *not* official board score receipts. No `sd-sm` or official branch has been modified or submitted.
