## Why the attempts lost
1. Every country/name membership is exact, but generator pool reuse creates `100k` canonical names rather than 3.32M; current shared exact dictionary already exploits that asymmetry. A flat one-cacheline key+membership layout reduced a dependent memory read, but adds false sharing and coherence invalidations to a hot lookup line.
2. The 62-bit morphology encoding is **deterministically injective** for generator `_word` forms: 630 syllable codes, 2/3-syllable surname (28 bits), 2-syllable given (19), 1-syllable middle (10), form (2), trailing-space count (3). Values outside this grammar have full-byte exact fallback. But parsing a syllable grammar on *every* row costs more than a CRC plus AVX2 equality check and makes the table larger.
3. Reverse-suffix parsing avoids chasing a quoted-note closing delimiter: the last two commas delimit `note,region_id,amount`. Yet discovering each true record boundary separately revisits all ~202MB and tests each LF; the repeat traversal outweighs the eliminated delimiter dependency. No full-system gain despite SIMD escaped-quote counting.
4. Four-stream field-stage interleaving makes row cursors independent but adds per-lane bookkeeping and pipeline overhead. Earlier two-cursor experiments were neutral. The complete four-cursor version measured slower even after retaining deferred dictionary batches.
5. Exactness does not permit adopting public long-name probabilistic fingerprints. Every valid canonical raw string must be differentiated, including hash collisions and trailing-space variants, with integer cents, BOM, embedded note LF and output ordering unchanged.
6. The prior isolated no-dictionary ablation reduced CPU approximately 305-315 -> 208ms, and removing name hashing an additional ~10ms. Thus dictionary and hashing together are important but not the only bottleneck. A 2.8x runtime frontier gap cannot plausibly be closed by improving either one little substage 5%.
7. Memory K penalizes event tapes, replicated dictionaries and sorting pipelines; previous full-engine radix/owner/private experiments lost despite reduced atomic sharing. These are evidence against their *tested physical realizations*, not impossibility proofs for every parallel grouping strategy.
